# AI MUSE — AI-Powered Fashion Shopping Website

AI MUSE is a modern, responsive fashion shopping website designed to help users explore fashion trends, discover outfit inspiration, and find styles that match their personality. It features a premium shopping-inspired interface with elegant animations and an AI stylist experience.

## ✨ Features

- **Premium Homepage** — Modern fashion landing page with an attractive hero section.
- **Fashion Categories** — Explore different fashion styles and outfit collections.
- **Outfit Collections** — Browse outfit cards with images and details.
- **AI Fashion Stylist** — Discover outfit recommendations based on style preferences.
- **Outfit Details** — View additional information about selected outfits.
- **Wishlist** — Save favorite outfits for later.
- **Customer Reviews** — Display customer feedback and experiences.
- **FAQ Section** — Answers to common questions.
- **Intro Animation** — Animated fashion-store opening screen.
- **Scroll Animations** — Smooth reveal effects while scrolling.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Modern UI** — Clean layouts, fashion photography, and interactive hover effects.

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- Lucide React
- Browser Local Storage
